# 🎬 Movie Management System

A beginner-friendly full-stack Movie Management CRUD application built using Node.js, Express.js, MySQL, HTML, CSS, and JavaScript.

## 🚀 Features

- ➕ Add Movies
- 📋 View All Movies
- ✏️ Update Movie Details
- 🗑️ Delete Movies
- 🔗 RESTful API Integration
- 🗄️ MySQL Database
- 🎨 Responsive Frontend

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- Postman
- Git & GitHub

## 📁 Project Structure

```
MovieManagement/

```

## ⚙️ Installation

```bash
git clone https://github.com/logashree187-kit/movie-management-system.git
cd movie-management-system
npm install
```

## ▶️ Run the Project

```bash
npm run dev
```

The application will run at:

```
http://localhost:3000
```

## 📌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /movies | Get all movies |
| GET | /movies/:id | Get movie by ID |
| POST | /movies | Add a movie |
| PUT | /movies/:id | Update a movie |
| DELETE | /movies/:id | Delete a movie |
